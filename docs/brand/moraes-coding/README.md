# Marca Moraes Coding

Direção visual B · Gráfico, aprovada em 2026-10-27. Fonte: o design system "Moraes Coding" no claude.ai (`https://claude.ai/artifact/CeaPqHJ1X5V61mPWYFZnTN`), versão de 2026-10-27.

- `tokens.json`: cores (temas Claro/Gelo e Escuro/Mata), tipografia (Space Grotesk e IBM Plex Mono), espaçamentos, raios e traços, com o contraste medido de cada par na nota de uso.
- `logo/`: os 11 SVGs oficiais do pacote `moraes-coding-marca.zip` (`04-logo/svg/`), com o texto em contornos. Padrão: `mc-horizontal-cor-fundo-claro.svg`. Mínimo: ícone com 24 px, horizontal com 120 px.
- `icones/`: os 36 ícones de interface, gerados dos traçados do componente Icone do design system. Grade de 24 px, traço de 2 px, pontas retas, tinta Mata `#0C2A1E`.

O manual de marca, as pranchas e o zip ficam fora do repositório, que é público: o manual traz o nome completo do Pedro.
